# Portfolio World

An interactive 3D portfolio. Instead of scrolling a page, you drive a
Suzuki Alto Works (a 3D model of the real car) through a world where
each stop is one part of my work.

## Features
- Drivable car loaded from a .glb model, with spinning wheels, steering
  and body lean
- Roads, trees, lamps, mountains, clouds and AI traffic
- Collisions with trees, signs and other cars
- Dusk and night modes with headlights
- Engine, crash and bird sounds
- Project boards for Metal Slug Remake, Tumble Pop Remake,
  AI Hand Detector, Image Editor and Fuel Expense Calculator
- Tech-logo boards and a motivation section
- Custom loading screen

## Controls
WASD or arrow keys to drive. Pull into a red circle to open it.
Use the top bar to jump to any stop.

## Tech
HTML, CSS, JavaScript, Three.js, GLTFLoader, Web Audio API
